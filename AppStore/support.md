## Русский

Приложение оценивает рост и вес ребёнка на 10 лет вперёд по справочникам ВОЗ. Это учебная оценка для родителей, не осмотр и не диагноз. Приложение не является медицинским изделием и не заменяет педиатра.

### Как пользоваться

1. Примите вводный экран.
2. Добавьте ребёнка: прозвище и справочник, мальчик или девочка.
3. Введите возраст, рост в сантиметрах и вес в килограммах. Можно добавить прошлые годы.
4. На экране ребёнка смотрите оценку, график и таблицу по годам.

Кнопка «Посмотреть пример» показывает готовую оценку. Этот профиль можно удалить.

Веб-версия открывается в браузере из папки `web` (нужен обычный веб-сервер, не файл с диска). Android-версия ставится из Google Play или из Android Studio. Расчёт во всех версиях один.

Оценка считается от последнего введённого возраста, а не от сегодняшней даты.

### Как удалить данные

Удалите измерение или весь профиль внутри приложения. Удаление приложения стирает всё, что оно сохранило на устройстве.

## English

The app estimates a child’s height and weight over the next 10 years from WHO references. It is an educational estimate for parents, not an examination and not a diagnosis. It is not a medical device and does not replace a pediatrician.

### How to use it

1. Accept the introduction.
2. Add a child: a nickname and which reference to use, boy or girl.
3. Enter age, height in centimetres, and weight in kilograms. Earlier years can be added too.
4. On the child’s screen, read the estimate, the chart, and the year-by-year table.

“View an example” opens a finished estimate. That profile can be deleted.

The web version runs in a browser from the `web` folder (use a normal web server, not a file opened from disk). The Android version is installed from Google Play or Android Studio. All versions use the same estimate.

The estimate is counted from the latest age you entered, not from today’s date.

### How to delete data

Delete a measurement or the whole profile inside the app. Deleting the app erases everything it stored on the device.
